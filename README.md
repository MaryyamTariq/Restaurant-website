# Saffron Spice Restaurant Website

A professional, multi-page, and fully responsive restaurant website built as a portfolio-ready frontend project. The website showcases signature dishes, a multi-category menu, restaurant background details, a visual gallery with lightbox effects, and an interactive contact form.

## Features

- **Multi-Page Layout:** Seamless navigation across Home (`index.html`), About (`about.html`), Menu (`menu.html`), Gallery (`gallery.html`), and Contact (`contact.html`) pages.
- **Responsive Design:** Built using CSS Flexbox and Grid, ensuring compatibility across mobile, tablet, and desktop screens with a mobile hamburger navigation menu.
- **Interactive Menu & Gallery:** Clean card layouts displaying authentic dishes with pricing, along with a visual gallery grid.
- **Form Validation:** JavaScript-powered validation for the contact form ensuring complete user inputs and valid email formatting with professional English alerts.
- **Performance Optimization:** Images optimized with lazy loading (`loading="lazy"`) to enhance initial page load speed.

## Tech Stack

- **HTML5:** Semantic document structure and markup.
- **CSS3:** Custom styling, layout design, and responsive media queries.
- **JavaScript (ES6):** Mobile navbar toggling, form input validation, and interactive UI behaviors.
